# ربات تلگرامی دانلود از دایرکت اینستاگرام

## این ربات چیکار می‌کنه؟
یک اکانت اینستاگرام مخصوص ربات داری. هر وقت کاربری از طریق دکمه **Share** یک پست
یا ریل رو به دایرکت اون اکانت بفرسته، ربات خودکار دانلودش می‌کنه و توی تلگرام
برای کاربر (به شرطی که قبلاً اکانتش رو با `/link` معرفی کرده باشه) می‌فرسته.

## ⚠️ نکات مهم قبل از استفاده
1. **این روش خلاف قوانین اینستاگرامه.** استفاده از `instagrapi` برای لاگین خودکار
   و پول کردن مداوم دایرکت، ریسک محدود شدن یا بلاک شدن اکانت اینستاگرام رو داره.
   پیشنهاد می‌کنم از یک اکانت فرعی (نه اکانت شخصی اصلی‌تون) استفاده کنید.
2. اینستاگرام ممکنه هنگام اولین لاگین از یک IP/دستگاه جدید، **چالش امنیتی
   (Checkpoint)** یا **کد دومرحله‌ای** بخواد. کد یا تاییدیه رو باید دستی وارد کنید
   (این کار توی ترمینال هنگام اجرای اول انجام می‌شه).
3. استوری‌ها معمولاً بعد از انقضا (۲۴ ساعت) دیگه قابل دانلود نیستن و اگه استوری
   منقضی‌شده share بشه، ربات نمی‌تونه دانلودش کنه.
4. پول کردن مداوم یعنی ربات هر ۴۵ ثانیه (قابل تنظیم) یک درخواست به اینستاگرام
   می‌زنه؛ این فاصله رو خیلی کم نکنید تا ریسک بلاک شدن پایین بمونه.

## پنل مدیریت (فول‌امکانات)
با ست کردن `ADMIN_TELEGRAM_IDS` توی تنظیمات Railway، دستور `/admin` توی تلگرام
یک پنل با دکمه‌های شیشه‌ای باز می‌کنه:
- 📊 آمار ربات (تعداد اکانت‌های متصل، وضعیت اینستاگرام، وضعیت پول کردن)
- 👥 لیست اکانت‌های متصل‌شده
- 🗑 حذف یک اتصال (با دکمه، فقط یوزرنیم رو تایپ می‌کنی)
- 🔌 وضعیت اتصال اینستاگرام
- 🔁 ورود مجدد دستی به اینستاگرام
- 🧹 پاک‌کردن سشن اینستاگرام (برای لاگین کاملاً از نو)
- ⏸/▶️ توقف یا شروع پول کردن دایرکت
- ⏱ تغییر فاصله‌ی چک دایرکت
- 📢 ارسال پیام همگانی به همه‌ی کاربرای متصل
- 🔧 تنظیم/تست/حذف پروکسی (VLESS یا HTTP/SOCKS5 معمولی) — **بدون نیاز به لمس Railway**

برای غیرادمین‌ها دستور `/admin` کار نمی‌کنه.

منوی کاربر عادی (`/start`) هم کاملاً دکمه‌ایه: اتصال/قطع اتصال اکانت
اینستاگرام و راهنما، بدون نیاز به تایپ کامند.

آیدی عددی تلگرامت رو می‌تونی از ربات [@userinfobot](https://t.me/userinfobot) بگیری.

## لاگین اینستاگرام؛ کد از داخل خود تلگرام
دیگه نیازی به ترمینال نیست. وقتی ربات اجرا می‌شه و اینستاگرام کد دومرحله‌ای یا
چالش امنیتی (Challenge) بخواد، ربات خودش یک پیام به ادمین (اولین آیدی توی
`ADMIN_TELEGRAM_IDS`) می‌فرسته و منتظر می‌مونه. ادمین کافیه همون لحظه کد رو
به‌صورت یک پیام معمولی برای ربات بفرسته.

⚠️ اگه `ADMIN_TELEGRAM_IDS` خالی باشه، ربات نمی‌تونه از کسی کد بخواد.

## ⚠️ خطای رایج: «blacklist» / «linked Facebook account»
اگه هنگام لاگین این پیام رو دیدی:
> You can log in with your linked Facebook account... blacklist of the Instagram Server

یعنی اینستاگرام **IP سرور** (مثلاً Railway) رو به‌خاطر دیتاسنتری بودنش مشکوک
تشخیص داده و لاگین رو رد کرده — این ربطی به درست/غلط بودن یوزر/پسورد نداره.
راه‌حلش استفاده از پروکسی‌ه (بخش بعد).

## تنظیم پروکسی — کاملاً از داخل تلگرام
دیگه لازم نیست چیزی توی Railway تنظیم کنی. دو نوع پروکسی پشتیبانی می‌شه:

### حالت ۱ — یک پروکسی معمولی HTTP/SOCKS5 داری
(مثلاً از یک سرویس مثل Webshare، IPRoyal، Bright Data و مشابه)

1. توی تلگرام `/admin` رو بزن
2. دکمه‌ی **«🔌 تنظیم پروکسی مستقیم (HTTP/SOCKS5)»** رو بزن
3. آدرس کامل رو بفرست، مثلاً:
   ```
   http://username:password@host:port
   ```

### حالت ۲ — یک کانفیگ VLESS/V2Ray داری
1. توی تلگرام `/admin` رو بزن
2. دکمه‌ی **«🔧 تنظیم پروکسی VLESS»** رو بزن
3. کل لینک `vless://...` رو (بدون هیچ تغییری) به‌صورت یک پیام بفرست

ربات خودش کانفیگ لازم برای `xray-core` رو می‌سازه و یک پردازش `xray` رو در
پس‌زمینه (داخل همون کانتینر) اجرا می‌کنه که یک پروکسی HTTP روی
`127.0.0.1:10809` باز می‌کنه.

هر دو حالت، مقداری که فرستادی رو توی `DATA_DIR` ذخیره می‌کنن تا بعد از هر
ری‌استارت هم دوباره خودکار وصل بشه (به شرطی که `DATA_DIR` روی یک Volume
ریلیوی باشه — به بخش «دیپلوی روی Railway» پایین‌تر نگاه کن).

### بعد از تنظیم (هر دو حالت)
- دکمه‌ی **«🧪 تست پروکسی»** رو بزن تا مطمئن بشی واقعاً و به‌صورت پایدار به
  اینستاگرام وصل می‌شه (نه فقط برقراره، بلکه قطع نمی‌شه وسط راه)
- اگه تست موفق بود، **«🧹 پاک‌کردن سشن»** بعد **«🔁 ورود مجدد به اینستاگرام»** رو بزن
- دکمه‌ی **«🗑 حذف پروکسی»** هر وقت خواستی، هر دو نوع پروکسی رو کامل غیرفعال می‌کنه

⚠️ نکته‌ی مهم: یک VPN/پروکسی عمومی (مثل خیلی از سرویس‌های ارزون V2Ray) یا حتی
پروکسی‌های **رایگان/Datacenter** بعضی سرویس‌های Residential، لزوماً IP مسکونی
واقعی نیستن و ممکنه بازم توسط اینستاگرام مشکوک تشخیص داده بشن، یا حتی تونلشون
وسط اتصال قطع بشه (خطای SSL/Connection reset). اگه دکمه‌ی «تست پروکسی» شکست
خورد یا بعد از وصل‌شدن بازم همون خطای لاگین رو دیدی، باید حتماً سراغ یک
**Residential Proxy واقعی** (نه Datacenter) بری.

### روش جایگزین (اختیاری): تنظیم از Railway
اگه ترجیح می‌دی همچنان از Railway مدیریت کنی، می‌تونی متغیر `IG_PROXY`
(پروکسی مستقیم) یا `PROXY_VLESS_URL` رو مستقیم توی Variables ست کنی — در این
صورت این مقدار همیشه اولویت داره و دکمه‌های تنظیم پروکسی توی پنل غیرفعال
می‌شن (چون دیگه چیزی برای مدیریت از پنل نمی‌مونه).


```bash
pip install -r requirements.txt
cp .env.example .env
```

فایل `.env` رو باز کن و این‌ها رو پر کن:
- `TELEGRAM_BOT_TOKEN`: از [@BotFather](https://t.me/BotFather) بگیر
- `INSTAGRAM_USERNAME` / `INSTAGRAM_PASSWORD`: اکانت مخصوص ربات

## اجرا

```bash
python bot.py
```

بار اول ممکنه توی ترمینال ازت کد دومرحله‌ای بخواد؛ وارد کن و منتظر بمون تا
سشن ذخیره بشه (فایل `ig_session.json`). دفعات بعد دیگه لازم نیست.

## نحوه استفاده (برای کاربر نهایی)
1. توی تلگرام به ربات پیام بده: `/start`
2. یوزرنیم اینستاگرامش رو معرفی کنه: `/link my_instagram_username`
3. از همون اکانت اینستاگرام، پست/ریل موردنظر رو با دکمه Share برای اکانت
   اینستاگرام ربات بفرسته.
4. ظرف چند ثانیه تا حداکثر ~۴۵ ثانیه، فایل توی تلگرام براش میاد.

## دیپلوی روی Railway

از اونجایی که کد ورود اینستاگرام حالا از طریق خود تلگرام پرسیده می‌شه، نیازی به
لاگین دستی از ترمینال قبل از دیپلوی نیست.

### مرحله ۱ — پروژه رو روی Railway بساز
1. کد رو به یک ریپازیتوری گیت‌هاب پوش کن (فایل `.env` به‌خاطر `.gitignore`
   آپلود نمی‌شه — همینطور باید باشه).
2. توی [Railway](https://railway.app) پروژه‌ی جدید بساز و ریپازیتوری رو وصل کن.
   Railway به‌خاطر `railway.json` و `Dockerfile` خودش می‌فهمه این یک **Worker**
   بدون پورت وبه (نیازی به فعال کردن دامنه/پورت نیست).

### مرحله ۲ — یک Volume اضافه کن (خیلی مهم)
فایل‌سیستم ریلیوی بین دیپلوی‌ها پاک می‌شه، پس اگه سشن و لینک‌ها رو ذخیره نکنی
هر دیپلوی جدید مجبوری دوباره لاگین کنی:
1. توی تنظیمات سرویس، بخش **Volumes** یک Volume جدید بساز (مثلاً با mount
   path برابر `/data`).
2. متغیر محیطی `DATA_DIR=/data` رو اضافه کن.

### مرحله ۳ — متغیرهای محیطی رو ست کن
توی تب **Variables** سرویس:
```
TELEGRAM_BOT_TOKEN=...
INSTAGRAM_USERNAME=...
INSTAGRAM_PASSWORD=...
ADMIN_TELEGRAM_IDS=...
DATA_DIR=/data
POLL_INTERVAL_SECONDS=45
```

### مرحله ۴ — دیپلوی کن و منتظر پیام تلگرام باش
بعد از استارت شدن سرویس، اگه اینستاگرام کد بخواد، ربات خودش به آیدی تلگرام
ادمین پیام می‌ده. کد رو همونجا (تو چت با ربات) بفرست تا لاگین کامل بشه.
از اون به بعد سشن توی Volume ذخیره می‌مونه و دیپلوی‌های بعدی نیازی به کد
دوباره ندارن (مگراینکه اینستاگرام سشن رو باطل کنه).

### مرحله ۵ — ریسک IP دیتاسنتر
سرورهای ریلیوی روی IP دیتاسنتری اجرا می‌شن که اینستاگرام بیشتر از IPهای موبایل/
خانگی بهشون شک می‌کنه و شانس Challenge خوردن یا بلاک موقت رو بالا می‌بره. اگه
این مشکل زیاد پیش اومد، یک پروکسی مسکونی (Residential Proxy) تهیه کن و مقدارش
رو توی متغیر محیطی `IG_PROXY` بذار (فرمت: `http://user:pass@host:port`).

## فایل‌های تولیدشده هنگام اجرا
- `ig_session.json` — سشن لاگین اینستاگرام (این فایل رو جایی به اشتراک نذار)
- `links.json` — نگاشت یوزرنیم اینستاگرام به chat_id تلگرام
- `seen_messages.json` — رهگیری پیام‌های پردازش‌شده (جلوگیری از ارسال تکراری)
- `downloads/` — پوشه‌ی موقت دانلود (فایل‌ها بعد از ارسال حذف می‌شن)

## محدودیت‌ها و پیشنهاد جایگزین
اگه ریسک بلاک شدن اکانت اینستاگرام برات مهمه، جایگزین ساده‌تر و بی‌خطرتر اینه که
کاربر مستقیماً **لینک** پست/ریل رو (نه از طریق دایرکت، بلکه با کپی/پیست) به خود
ربات تلگرام بفرسته و ربات با `yt-dlp` دانلودش کنه — بدون نیاز به لاگین اینستاگرام
و بدون ریسک بلاک شدن. اگه بعداً خواستی این نسخه رو هم بسازم بگو.
